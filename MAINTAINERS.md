# Maintainers

DNScale OÜ maintains this webhook and its container images. The GitHub
maintenance account is [@dnscale-ops](https://github.com/dnscale-ops).

Report reproducible webhook problems through
[GitHub issues](https://github.com/dnscaleou/external-dns-webhook-dnscale/issues).
Include the webhook, ExternalDNS, Helm chart, and Kubernetes versions and
sanitized logs. For account or API access questions, contact
[support@dnscale.eu](mailto:support@dnscale.eu).
Report vulnerabilities using [SECURITY.md](SECURITY.md).

DNScale maintains this external integration independently of the ExternalDNS project.
