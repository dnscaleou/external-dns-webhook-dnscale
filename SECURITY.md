# Security

Report suspected vulnerabilities privately to
[security@dnscale.eu](mailto:security@dnscale.eu), following the
[DNScale vulnerability disclosure policy](https://dnscale.eu/learning/dnscale-vulnerability-disclosure-policy).
Include affected versions and sanitized reproduction steps. Request a secure
exchange channel before sending sensitive material. Do not open a public issue
containing credentials, customer DNS records, or exploit details.

Security fixes are published in new releases. Use the latest webhook release;
published image tags are not overwritten. The tested ExternalDNS, chart, and
Kubernetes versions are documented in the README.
